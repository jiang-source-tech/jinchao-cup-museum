# 决策记录

本目录用于记录小芯项目的产品和技术决策。

决策记录应短、明确、带日期。推荐文件名格式：

```text
YYYY-MM-DD-short-topic.md
```

推荐结构：

```markdown
# 决策标题

## 背景

说明发生了什么变化，或什么问题迫使项目必须做选择。

## 决策

写清楚小芯最终选择什么方案。

## 影响

写清楚这个选择让什么事情变简单、什么事情变困难、什么事情被有意推迟。
```
