# 小芯控制台实施计划

本文是 2026-07-03 的历史实施计划归档。原目标是在服务端 HTTP 端口上建立小芯控制台，用于设备列表、事件投递、ACK 状态和演示触发。

## 目标

建立 `/xiaoxin/control/` 和 `/api/xiaoxin/...`，让服务端可以向设备投递通知事件、跟踪投递状态，并在设备睡眠时通过 MQTT 唤醒。

## 核心能力

- 设备注册和在线状态。
- 投递请求、投递状态机和失败原因。
- MQTT doorbell wake。
- WebSocket 下发 `xiaoxin_event`。
- 固件 ACK 回传。
- 控制台页面展示设备、事件、投递和测试入口。
- TTS 播报完成状态回写。

## 实施任务

1. 定义服务端控制类型和 payload 构造器。
2. 建立设备注册表和投递存储。
3. 建立 MQTT 唤醒客户端。
4. 建立事件调度器。
5. 增加 HTTP API 和浏览器控制台。
6. 打通 HTTP、WebSocket 和运行时。
7. 增加连接注册、ACK 处理和 TTS 完成处理。
8. 在固件端解析 `xiaoxin_event` 并发送 ACK。
9. 补充端到端文档和验证。

## 验收

- 在线设备能收到服务端投递事件。
- 可唤醒设备能先进入 `waking`，重连后继续投递。
- 离线设备能得到明确失败原因。
- 固件能回传 ACK，服务端能更新投递状态。
- 控制台能展示设备、投递历史和失败原因。

## 当前状态

控制台基础方向已经形成，但独立账号、设备所有权和记忆主体管理仍由 `XIAOXIN-004`、`XIAOXIN-005` 和身份记忆控制台计划继续跟踪。
