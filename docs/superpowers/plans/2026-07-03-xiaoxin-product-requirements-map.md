# 小芯产品需求地图实施计划

本文是 2026-07-03 的历史实施计划归档。原目标是把小芯的产品能力拆成可视化需求地图，帮助区分服务端、固件、运维和产品化任务。

## 目标

建立一个可维护的需求源文件和本地可视化页面，让项目状态不再只散落在对话、实现计划和代码注释中。

## 实施任务

1. 建立需求源文件，记录能力、状态、优先级、依赖和验收条件。
2. 建立本地服务，读取需求源并输出 JSON。
3. 建立可视化页面，用筛选、分组和详情面板展示需求。

## 验收

- 能从页面看到每个能力处于什么状态。
- 能区分已实现、开发中、待实现和可优化事项。
- 能追踪关键依赖和验收条件。
