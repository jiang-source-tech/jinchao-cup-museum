# 小芯开发看板实施计划

本文是 2026-07-03 的历史实施计划归档。原目标是建立一个本地开发看板，把产品路线拆成阶段、泳道、模块和任务。

## 目标

用 YAML 记录开发任务，用本地服务和 HTML 页面渲染任务状态，帮助区分“想法”“可开发”“开发中”“阻塞”和“已完成”。

## 数据模型

计划中的 YAML 包含：

- `meta`
- `taxonomy`
- `phases`
- `lanes`
- `modules`
- `tasks`

每个任务需要记录标题、状态、泳道、阶段、优先级、类型、模块、来源需求、摘要、细节、文件、依赖、阻塞对象、验收、验证、风险和估算。

## 阶段划分

1. 本地测试控制台 MVP。
2. 正式 Product API MVP。
3. 微信小程序 MVP。
4. 商业化与运营能力。

## 实施任务

1. 创建开发看板 YAML。
2. 增加本地服务路由和校验。
3. 创建开发看板 HTML。
4. 做端到端验证和错误处理。

## 当前状态

后续更适合作为 `docs/requirements/requirements.yaml` 的扩展，而不是维护第二套状态源。本文保留为历史设计，不作为当前唯一事实源。
