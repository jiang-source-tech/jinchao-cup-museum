# 小芯文档重组实施计划

本文是 2026-07-01 的历史实施计划归档。原目标是把上游文档归档，并建立面向小芯二次开发的中文文档中心。

## 目标

把原始小智文档从当前主文档入口中移走，放入 `docs/upstream-archive/` 作为参考资料；同时创建小芯自己的入门、开发、运维和决策文档。

## 目录策略

- `docs/README.md` 作为文档中心入口。
- `docs/getting-started/` 放部署、模型供应商和首次运行检查。
- `docs/development/` 放架构、定制开发、运行路径和小芯专用能力说明。
- `docs/operations/` 放排障、备份和升级。
- `docs/decisions/` 放决策记录入口。
- `docs/upstream-archive/` 只保留上游资料，不参与小芯 active docs 的中文化维护。

## 实施任务

1. 归档上游文档和资产。
2. 创建入门文档。
3. 创建开发文档。
4. 创建运维文档、决策目录和文档索引。
5. 验证文档链接、目录结构和关键路径说明。

## 验收

- 小芯文档入口清楚指向当前 active docs。
- 上游文档不会与小芯当前部署说明混在一起。
- 新用户能从文档中心找到部署、模型、路径、排障和备份信息。

## 后续维护

文档中心应优先记录小芯当前事实。上游文档只能作为参考，不能再作为默认部署依据。
