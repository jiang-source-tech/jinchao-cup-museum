# 小程序统一课程提醒设置

每个学生账户有一项统一的课程提醒提前量。新账户默认值为 **15 分钟**；该设置对该学生的所有课程生效，不支持按单门课程覆盖。

将设置入口放在课表页的独立“课程提醒”区域，而不是每一门课程的编辑表单中。页面加载时读取当前值；用户选择新分钟数并确认后保存。可选值为 0 至 120 的整数分钟，其中 0 表示准点提醒。

## 读取设置

`GET /api/miniprogram/course-reminder-settings`

响应：

```json
{
  "success": true,
  "courseReminderSettings": {
    "remindBeforeMin": 15
  }
}
```

## 更新设置

`PATCH /api/miniprogram/course-reminder-settings`

请求：

```json
{
  "remindBeforeMin": 30
}
```

成功响应与读取响应相同。缺失字段、非整数或超出 `0` 至 `120` 的值会返回 HTTP 400。

## 调度语义

课程在“课程开始时间减去 `remindBeforeMin`”时进入提醒队列。例如课程 08:00 开始，设置为 15 分钟时，最早于 07:45 投递；设置改为 30 分钟后，后续未提醒课程最早于 07:30 投递。

已经为某次课程投递过的提醒不会因后续修改统一设置而重复投递。`remindBeforeMin` 只决定课程何时进入提醒队列，不再直接写入通知文案。由于设备可能离线、通知可能延迟投递，正文和语音统一使用不会随投递时间失真的绝对上课时间，例如“高等数学 08:00”和“小芯提醒你，08:00有高等数学课”。

课程提醒的有效期截止到该课次的 `startsAt`。设备在课程开始时或开始后才上线，服务端会把排队中的提醒标记为已过期，不再发送卡片或播放语音。设备离线只表示当时不具备投递条件，系统不会据此判断学生迟到，也不会生成迟到提醒。

若提前时间跨越午夜，例如次日 00:10 的课程设置为提前 15 分钟，服务端会在前一日 23:55 投递提醒。
