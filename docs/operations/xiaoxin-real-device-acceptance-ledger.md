# 小芯真机闭环验收台账

本文用于记录小芯从服务端、小程序、控制台到硬件端的真实闭环验收。它不是功能说明，也不是测试计划草稿；每一条验收记录都必须能回答一个问题：这台真实设备、这个真实账号、这次真实投递，到底有没有跑通。

## 验收目标

第一阶段只验收最小可用闭环：

```text
硬件开机联网
  -> 请求 /xiaoxin/ota/
  -> 出现在 /xiaoxin/control/
  -> 小程序账号绑定设备
  -> 小程序或控制台创建提醒/通知
  -> 服务端投递到硬件
  -> 硬件展示并播报
  -> 硬件回 ACK / TTS done
  -> 服务端保存投递状态
  -> 小程序或控制台可回看结果
```

如果这条链路没有证据，不要继续声称“已经完成产品闭环”。

常见最终状态：

- `done`：硬件收到并完成所需流程。
- `failed` + `device_offline`：设备无法投递，且没有可用门铃唤醒路径。
- `failed` + `wake_timeout`：门铃已尝试唤醒，但设备没有在超时时间内重连。
- `failed` + `ack_timeout`：事件已发送，但设备没有确认收到。
- `failed` + `tts_failed`：播报链路失败或播放完成状态没有按预期回传。
