小芯 OTA 发布速查表

默认策略：新版本、干净构建、哈希核对、草稿先行、单设备灰度、看到 committed、测试后暂停。

四个占位符

占位符示例
<VERSION>0.1.3
<SERVER_IP>读取你的服务器信息文件，不要公开密码
<DEVICE_ID>测试设备标识，不要公开
<RELEASE_ID>创建草稿后输出的 rel-...

Windows：构建与校验

$Version = "<VERSION>"
$Repo = "D:\Learn\hzcu_xiaoxin_firmwire_private"
$Dir = Join-Path $Repo ".worktrees\ota-release-$Version"
Set-Location $Repo
git fetch origin
git worktree add -b "release/ota-$Version" $Dir origin/codex/ota-firmware-bootstrap
Set-Location $Dir

# 手工把 CMakeLists.txt 中 PROJECT_VER 改为 $Version
# 确认 sdkconfig 含：# CONFIG_CODEC_I2C_BACKWARD_COMPATIBLE is not set

& "D:\Espressif\frameworks\esp-idf-v5.5.4\export.ps1"
idf.py build
$Tests = Get-ChildItem tests -Filter "ota_*.py" | % FullName
python -m pytest -q @Tests
python tools\verify_xiaoxin_ota_release.py --build-dir build
Get-FileHash build\ai_pet.bin -Algorithm SHA256
Get-Item build\ai_pet.bin | Select Length

服务器：草稿与单设备发布

cd /opt/xiaoxin-work/xiaoxin-esp32-server/main/xiaozhi-server
VERSION="<VERSION>"
SOURCE="data/ota-inbox/ai_pet-$VERSION.bin"
DEVICE_ID="<DEVICE_ID>"

sha256sum "$SOURCE"
stat -c '%s bytes' "$SOURCE"

docker exec xiaozhi-esp32-server python scripts/publish_firmware.py \
  --source "$SOURCE" \
  --database data/xiaoxin_firmware_releases.db \
  --artifact-dir data/xiaoxin_firmware \
  --model esp32-s3-touch-lcd-1.46 \
  --version "$VERSION" \
  --board-type esp32-s3-touch-lcd-1.46 \
  --partition-layout-id xiaoxin-ota-16m-v1 \
  --channel stable \
  --esp-idf-version 5.5.4 \
  --rollout-percentage 0 \
  --allow-device "$DEVICE_ID"

RELEASE_ID="<RELEASE_ID>"
PUBLIC_OTA_URL="http://<SERVER_IP>:8003/xiaoxin/ota/"

docker exec xiaozhi-esp32-server python scripts/publish_firmware.py \
  --operation set-state --release-id "$RELEASE_ID" --state published \
  --database data/xiaoxin_firmware_releases.db \
  --artifact-dir data/xiaoxin_firmware \
  --public-ota-url "$PUBLIC_OTA_URL" --allow-insecure-http

验收与暂停

docker exec xiaozhi-esp32-server python scripts/publish_firmware.py \
  --operation observations --release-id "$RELEASE_ID" \
  --database data/xiaoxin_firmware_releases.db \
  --artifact-dir data/xiaoxin_firmware

# 成功必须出现 result=committed、current_version=<VERSION>

docker exec xiaozhi-esp32-server python scripts/publish_firmware.py \
  --operation set-state --release-id "$RELEASE_ID" --state paused \
  --database data/xiaoxin_firmware_releases.db \
  --artifact-dir data/xiaoxin_firmware
失败时：先 paused，保留日志，不覆盖同一个版本，不替换已导入制品；修复后使用新版本号。
