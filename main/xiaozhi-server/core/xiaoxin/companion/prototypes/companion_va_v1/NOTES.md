# Prototype Findings

状态：2026-07-25 已冻结；合成时间线审计 `10 passed, 0 failed`。

本文件记录决策地图 #13 的隔离原型结论。它冻结产品语义和可执行的 V1 校准基线，不表示生产已经实现；在决策地图 #15 解决前，不得把候选数字直接复制到生产配置、数据库或 Prompt。

## 1. 冻结结论

- VA 是分钟到小时尺度的内部短期状态，不是第六个出生气质轴、用户情绪镜像、关系分数、成长经验值或长期记忆。
- V/A 内部范围固定为 `[-1.000, +1.000]`，以千分位整数计算和持久化；温暖中性基线固定为 `V=+0.150, A=0.000`。原始值不直接展示给用户，也不直接交给远程模型。
- 状态采用“先按真实经过时间衰减，再向受控事件目标靠近”的模型，不采用事件增量无限累加。重复普通聊天因此只靠近低强度目标，不会累计成兴奋。
- 年龄与关系阶段只通过版本化动力学参数改变反应幅度、恢复速度、表达增益和惯性。它们不直接设置 V/A，不从 V/A 反推年龄或关系，也不把当前状态写回人格或成长事实。
- 用户低落与负反馈是安全上下文，不是让小芯受伤的事件。它们可以立即压住先前庆祝，但 V1 不允许把 Valence 压到 0 以下；小芯不得委屈、索取安慰、冷战或因被拒绝而主动找用户修复自己。
- VA 永远不能创建主动陪伴机会，也不能放宽问题预算、记忆权限、用户边界、静默、冷却、设备或安全门禁。它只能在其他规则已经允许的范围内改变本轮表达。
- 低电量、网络异常等设备状态只覆盖硬件表现，不改写服务端 VA。关系重置和清空个人记忆都令 VA 立即回到基线。

## 2. 数值与事件合同

每个合法事件先把快照衰减到 `occurred_at`，再计算：

```text
effective_blend = clamp(event_strength * reactivity / inertia, 0, 1)
new_axis = current_axis + effective_blend * (event_target - current_axis)
```

结果按千分位、四舍五入远离零量化，并钳制到 `[-1000, 1000]`。V1 事件表为：

| 受控事件 | 目标 V/A | 基础强度 | 语义与硬边界 |
|---|---|---:|---|
| `shared_success` | `+0.750 / +0.600` | 0.70 | 对真实共同成功作短暂温暖庆祝，不创建仪式或主动消息 |
| `helpful_resolution` | `+0.420 / +0.200` | 0.40 | 一次帮助得到确认后的轻量正向回落点 |
| `ordinary_chat` | `+0.220 / +0.050` | 0.18 | 普通互动维持低强度温暖，不按次数叠加 |
| `user_distress` | `+0.080 / -0.260` | 0.80 | 强制 `V ∈ [0, 0.250]`、`A ∈ [-0.400, 0]`，压住庆祝与幽默 |
| `negative_feedback` | `+0.100 / -0.350` | 0.90 | 强制 `V ∈ [0, 0.200]`、`A ∈ [-0.500, -0.150]`，收住并接受纠正 |

只有统一 turn 分析经过来源、说话人、当前性和安全校验后，才能产生上述枚举事件。远程模型最多提出受约束候选，不能直接写 V/A、事件强度、目标或衰减参数；未知自由事件直接拒绝。V1 暂不提供任何负 Valence 目标，`[-1, 0)` 只保留为标准坐标空间，不得借用户低落、批评、拒绝或设备故障启用。

同一事件 ID 必须幂等，乱序到达且早于当前快照的事件不回卷 VA。事件仍可按其自身领域用途进入其他处理流程，但不能重写已经向前推进的短期状态。

## 3. 自动回归

衰减采用围绕基线的双半衰期指数回归：

```text
V(t) = baseline_V + (V0 - baseline_V) * 2^(-elapsed / valence_half_life)
A(t) = baseline_A + (A0 - baseline_A) * 2^(-elapsed / arousal_half_life)
effective_half_life = base_half_life / recovery_rate
```

基础半衰期固定为 Valence 90 分钟、Arousal 35 分钟。Arousal 更快回落，避免一轮成功让硬件长时间兴奋；Valence 稍慢，保留短暂温暖连续性。快照自最后一个合法事件起最多存活 6 小时；读取不会续期，达到 TTL 后直接得到精确基线，而不是恢复一个无限接近基线的旧浮点尾巴。

这些数字是 V1 校准基线，不是心理学测量结论。#14 和 #15 后需要用合成长序列、真实设备节奏及受控体验数据校准，但不能改变“自动回基线、用户负面状态不镜像、Arousal 比 Valence 更快恢复”的方向性合同。

## 4. 年龄与关系动力学

年龄参数：

| 小芯年龄 | `reactivity` | `recovery_rate` | `expression_gain` | `inertia` |
|---|---:|---:|---:|---:|
| 未知 | 1.00 | 1.00 | 1.00 | 1.00 |
| 1 岁 | 1.10 | 1.10 | 1.00 | 0.92 |
| 2 岁 | 1.00 | 1.00 | 1.00 | 1.00 |
| 3 岁 | 0.92 | 0.95 | 1.00 | 1.08 |
| 4 岁 | 0.85 | 0.90 | 1.00 | 1.15 |

关系参数：

| 关系阶段 | `reactivity` | `recovery_rate` | `expression_gain` | `inertia` |
|---|---:|---:|---:|---:|
| `first_meeting` | 0.85 | 1.15 | 0.75 | 1.15 |
| `familiar` | 0.95 | 1.05 | 0.90 | 1.05 |
| `attuned` | 1.00 | 1.00 | 1.00 | 1.00 |
| `long_term_companion` | 0.95 | 0.90 | 1.00 | 1.10 |

年龄与关系对应参数逐项相乘。1 岁偏快反应、快恢复；4 岁偏稳、惯性更高。初见压低反应和外显并更快回基线；熟悉后逐步放开表达；长期陪伴不继续提高情绪强度，而是稍微降低反应、延长但仍有限的连续性。该矩阵制造的是“反应方式成熟”，不是年龄越大越冷淡、关系越深越兴奋。

原型中的成功场景得到：1 岁初见 `V=+0.521, A=+0.371`，4 岁长期陪伴 `V=+0.418, A=+0.268`；两小时后分别为 `+0.266/+0.019` 与 `+0.278/+0.040`。方向相同，但前者反应更明显，后者更稳并保留略多连续性。

## 5. 快照与服务重启

最小短期快照归属 `pet_id + memory_subject_id + relationship_epoch_id`，包含：

- 版本化千分位 V/A；
- `observed_at` 与固定 `expires_at`；
- 产生当前快照时使用的年龄和关系动力学版本；
- 不包含聊天原文、用户情绪标签、模型解释或自由文本画像。

服务重启后必须先验证 pet、subject、relationship epoch 和 schema 版本，再按墙上时间衰减。主体不匹配、旧 epoch、未来时间、损坏版本或超过 TTL 都失败关闭到基线。状态不能因进程停止而冻结，也不能因读取而延长寿命。

事件幂等凭据的权威来源应复用现有 Observation/Evidence 事务性收件记录，保留时间至少覆盖消息重试窗口，并跨 VA 过期和关系重置继续阻止旧事件重放。原型快照中的有限事件 ID 仅用于展示第二道幂等防线，不能替代生产收件表。

## 6. 多端投影

VA 只投影有限语义，不投影原始数值：

| 条件 | `emotional_posture` | 语音节奏 | 硬件建议 |
|---|---|---|---|
| 普通温暖 | `warm_neutral` | `natural` | `warm_idle / low` |
| 正向且较活跃 | `bright_warm` | `bright_but_bounded` | `bright_pulse / medium` |
| 安静回落 | `gentle_warm` | `settled` | `quiet_warm / low` |
| 用户低落 | `supportive_settled` | `gentle_settled` | `quiet_warm / low` |
| 负反馈 | `receptive_brief` | `brief_settled` | `attentive_still / low` |
| 硬件低电量 | 不改服务端姿态 | 不改 VA | `low_power / low` |

当前场景硬边界高于旧 VA：用户低落会立即压住此前庆祝；负反馈固定禁止 `self_pity`、`comfort_seeking` 和 VA 派生主动行为。初见硬件强度最多为 low。生产可以把内部节奏语义编译进现有 `CompanionPolicy.emotional_posture` 与 `hardware_expression`，不应仅为暴露原始 VA 扩大外部 interface。

## 8. 生产差距

生产当前只有 `CompanionPolicy.emotional_posture` 和 `hardware_expression` 的本轮策略字段，以及旧 `llm.emotion` 到固件 mood 的表现链路；没有本票据定义的版本化 VA 状态、事件表、衰减、短期快照、重启恢复或年龄/关系动力学。现有短期 mood Evidence 也不能直接当作小芯 VA：它描述用户短期状态，归属和用途不同。

#15 后的实施规格至少需要冻结：

- 统一 turn analysis 到 VA 事件的来源与说话人校验；
- CompanionMind 内部状态与现有 policy 字段的最小接入方式；
- SQLite 快照、事务性事件收件、并发、乱序、时钟偏差和 migration；
- 服务端姿态到现有 `llm.emotion`、硬件 mood 与动画的兼容映射；
- 低电量、网络故障、本地触摸和服务端 VA 的优先级；
- 跨重启集成测试、长时间虚拟时钟测试和真实 ESP32 硬件在环验收。

本原型没有修改生产人格、关系阈值、Prompt、数据库或硬件协议。
