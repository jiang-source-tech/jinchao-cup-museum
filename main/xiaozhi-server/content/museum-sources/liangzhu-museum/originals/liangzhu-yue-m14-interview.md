# 反山M14玉钺组合考古访谈摘编

本文件由金潮杯博物馆项目根据澎湃新闻刊载的杨楠访谈整理，只保存可核对的事实摘要，不是访谈全文、发掘日志或馆方审核稿。

## 发现与整理

反山遗址于1986年发掘，杨楠负责M14等墓葬的发掘和绘图。清理M14时，考古人员在玉钺穿孔附近发现细小黄色玉粒，并逐颗保留其位置，最终识别出一条由近百颗玉粒组成、长约70厘米的玉粒带。

## 组合复原

近百颗玉粒在玉钺周围连续分布约70厘米，玉钺两端还发现玉瑁和玉镦。现场分析据此推测，已经腐烂的木质把柄原本穿过玉钺并连接玉瑁、玉镦，木柄表面镶嵌或粘贴着密集玉粒；由此复原出这套玉钺组合的基本结构。

## 材质与保存

玉钺、玉瑁、玉镦和近百颗小玉粒为玉质部件，承载它们的把柄为木质。木柄已经腐烂，考古复原主要依靠玉粒带的保存位置以及玉钺、玉瑁和玉镦之间的连接关系。

## 用途解释

访谈把完整组合称为豪华仪仗性武器，并指出反山大墓中的玉钺象征墓主人生前可能拥有军权。这个解释说明器物的权力象征功能，不等于已经知道墓主人在某一次活动中的具体动作。

## 证据边界

现有公开信息能够支持玉钺、玉瑁、玉镦、木柄和约70厘米玉粒带之间的组合关系；原木柄没有保存，玉粒的具体固定细节和实际持握动作不能直接观察。
