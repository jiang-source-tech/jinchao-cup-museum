# 杭州网战国水晶杯文章事实摘编

本文件由金潮杯博物馆项目根据杭州网公开文章整理，只保存事实摘要，不是网页全文或馆方审核稿。

## 材料与尺寸

文章将器物识别为整块天然水晶琢制的杯形器，并记录高15.4厘米、口径7.6厘米、底径5.2厘米。发掘者访谈则记录口径7.8厘米、底径5.4厘米；两组数据的差异应保留在证据层，正式展陈前需由馆方测量档案确认。

## 历史地位

文章将其称为我国出土的早期水晶制品中器形最大的一件，并记录它于2002年1月18日列入首批禁止出国（境）展览文物名录。

## 工艺难点

文章讨论了两类加工解释：一种设想使用管钻掏挖内膛，另一种设想借助金刚砂等磨料研磨。由于杯体内膛上宽下窄且表面光洁，具体如何取芯、使用何种工具和怎样完成内壁抛光仍无定论。可靠讲解应把这些技术设想写成推测，而不是确定工序。
